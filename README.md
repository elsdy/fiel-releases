# Fiel 배포

맥용 파일 탐색기 **Fiel** 의 설치 파일과 업데이트 목록을 내려받는 곳입니다. 코드는 여기에 없습니다.

- **내려받기:** [Releases](https://github.com/elsdy/fiel-releases/releases) 에서 가장 새 판의 `Fiel-<판>.dmg` 를 받습니다.
- **업데이트:** 앱이 이 저장소의 가장 새 판에 올린 `update.txt` 를 보고 새 판을 알립니다. 파일은 Fiel 의 서명(Ed25519)으로 확인한 뒤에만 설치됩니다.
- **요구:** macOS 14 이상, Apple 실리콘(arm64).
- **체험:** 14일 동안 모든 기능을 쓸 수 있고, 그 뒤에는 구매한 열쇠를 넣어 계속 씁니다.
